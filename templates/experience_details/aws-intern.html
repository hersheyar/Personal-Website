Software Development Engineer Intern

Amazon Web Services (AWS) · Seattle, WA · Summer 2023

I interned at Amazon Web Services (AWS) during Summer 2023 as a Software Development Engineer Intern. I worked on the Qraken project, a query-driven ticketing system used for internal issue tracking and automation workflows.

My primary contribution was developing backend Kotlin code and integrating several AWS services to automate and streamline query execution. I designed and configured AWS Step Functions for orchestration, and used Lambda to handle logic.

I also implemented EventBridge cron rules to trigger Lambdas for scheduled queries and used DynamoDB for data. Query execution was offloaded to Athena, and results stored in S3.

This internship was very fast-paced I really enjoyed learning and getting that opportunity. It gave me a great first exposure to AWS.

Technologies Used

Kotlin AWS Lambda AWS EventBridge AWS Step Functions AWS DynamoDB Amazon Athena S3
