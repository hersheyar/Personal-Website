Cloud Migration & Automation

As a Junior Cloud Software Engineer at Koniag Government Services, I’ve helped modernize legacy on-prem systems for the Navy’s meteorology and oceanography command by migrating them into the AWS cloud.

I deployed EC2 instances running RHEL 8, configured Apache and Tomcat, and migrated Java .war applications into the cloud environment. To streamline this, I created CloudFormation templates for spinning up EC2 environments in minutes.

I wrote Bash scripts to automate the configuration of Apache and Tomcat, and executed them using SSM Run Command for rapid, consistent deployment across multiple EC2s.

I mounted S3 buckets for shared data access, and configured a reverse proxy environment to support ArcGIS Web Adaptor, Server, and Portal. These systems were deployed with security roles and maintenance schedules tailored using SSM.

I also built synthetic canaries to test our web applications from a user perspective, ensuring core links and functionality stay live.

Technologies Used

AWS EC2 RHEL 8 Apache Tomcat .war SSM S3 CloudFormation Bash Reverse Proxy ArcGIS Canary
